# ficha-de-rpg
### Um criador de ficha de RPG simples em Python de nenhum sistema específico.

Criei esse projeto no primeiro semestre da universidade no começo de 2025.

Enquanto organizava arquivos antigos, decidi pegar esse código e melhorá-lo, com o que sei hoje no terceiro semestre.

Pretendo tornar ela funcional para criar, editar, exportar, importar e armazenar fichas completas de personagens jogáveis para um sistema de RPG de mesa próprio.
